## 🎓 ما الذي ستتعلمه

### المبادئ الأساسية
- ✅ مقدمة عن نظام Git
- ✅ التثبيت والإعداد الأولي
- ✅ الأوامر الأساسية
- ✅ إدارة الفروع (Branches)
- ✅ دمج التغييرات (Merging)
- ✅ التعامل مع GitHub

### المهارات المتقدمة
- 🔹 إعادة تعديل التاريخ (Rebasing)
- 🔹 إنشاء العلامات (Tags)
- 🔹 إدارة الصراعات (Conflict Resolution)
- 🔹 سير عمل Gitflow
- 🔹 أفضل الممارسات

## 🚀 البدء السريع

```bash

# فتح الموقع محلياً

```

## 📖 محتوى الدورة

### الوحدة 1: الأساسيات
1. **ما هو Git؟** - شرح كامل
2. **التثبيت** - على جميع الأنظمة
3. **الإعداد الأول** - خطوات التهيئة

### الوحدة 2: الأوامر الأساسية
1. `git init` - إنشاء مستودع
2. `git add` - إضافة الملفات
3. `git commit` - حفظ التغييرات
4. `git push` و `git pull` - التزامن

### الوحدة 3: الفروع والدمج
1. إنشاء وإدارة الفروع
2. دمج الفروع بنجاح
3. حل الصراعات

## 💻 المتطلبات

- متصفح حديث
- اتصال إنترنت
- Git مثبت على جهازك (اختياري)

## 🎯 الأهداف التعليمية

بعد انتهاء الدورة ستتمكن من:
- ✨ استخدام Git بكفاءة في مشاريعك
- ✨ التعاون مع فريق عمل
- ✨ إدارة الإصدارات المختلفة
- ✨ العمل مع GitHub واستخدام Pull Requests
- ✨ تطبيق أفضل ممارسات التطوير
